# Communal Service Management System

JavaFX-приложение для управления данными о коммунальных услугах и жильцах. Проект работает с базами данных PostgreSQL и Microsoft SQL Server через JDBC и поддерживает разные роли пользователей.

## Основной функционал

### Учётная запись жильца

* Просмотр личной информации
* Просмотр текущей задолженности
* Просмотр истории показаний с фильтрацией:

  * по периоду
  * по типу услуги
* Просмотр истории оплат с фильтрацией по периоду
* Оплата задолженности
* Отображение информации о льготах

### Учётная запись оператора

* Поиск жильцов по имени и фамилии
* Просмотр полной карточки жильца
* Просмотр истории показаний и оплат выбранного жильца
* Добавление показаний
* Управление домами
* Управление квартирами
* Управление жильцами
* Обновление тарифов коммунальных услуг
* Изменение процентов льгот
* Добавление, редактирование и удаление данных

## Настройка подключения

Перед запуском необходимо настроить файлы:

```text
config/postgresql.properties
config/sqlserver.properties
```

Пример:

```properties
driver=org.postgresql.Driver
url=jdbc:postgresql://localhost:5432/communal_service
user=postgres
password=12345
```

## Запуск приложения

1. Перейти в консоли в папку:

```text
dist
```

2. Выполнить команду:

```bash
java -cp "communal_service.jar;lib/*" UI.MainApp
```
